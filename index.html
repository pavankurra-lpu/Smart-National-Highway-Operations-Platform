About SNHOP

PORTFOLIO SIMULATION This is a comprehensive frontend simulation built for demonstration purposes. No real monetary transactions are processed, and no real emergency services are contacted.

The Vision

When I started creating this page, my goal was to build an end-to-end simulation of India's highway operations. I wanted to see if I could combine FASTag tolling logic, emergency SOS routing, and live traffic analytics into a single, cohesive interface that seamlessly syncs between a Traveller Portal and an Admin Control Room.

System Architecture

To make this work purely in the browser without deploying a heavy backend, the platform uses a highly customized localStorage event bus. This allows the User Portal and Admin Portal to communicate in real-time across browser tabs.

graph TD A[Traveller Portal] <-->|localStorage Event Bus| B[(Browser Storage)] C[Admin Operations Room] <-->|localStorage Event Bus| B B -.-> D[Live Positions] B -.-> E[FASTag Wallet & History] B -.-> F[SOS Incident Queue]

Key Technical Highlights

  • OSRM Routing: Integrates with Open Source Routing Machine to calculate accurate driving paths and distances.
  • Spatial Intersections: Analyzes polyline routes against a database of 1,232+ Indian toll plazas to accurately predict passage costs.
  • Live State Sync: Uses native storage events to allow admins to resolve emergencies while the user watches the status update live.
